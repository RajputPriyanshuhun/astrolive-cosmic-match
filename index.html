Product rationale

Why this is structurally viral

Most astrology apps ask users to please share. Cosmic Match makes sharing the only way to use the core feature: a one-sided chart is incomplete by design, so every session that reaches value creation produces exactly one outbound invite to a specific, real person — not a broadcast post.

  • Double-sided unlock: the report literally cannot render without a second real profile — modeled on the mechanic behind Co-Star's compatibility checks and dating-app match reveals.
  • Directed, not broadcast: invites go to one named person via WhatsApp, which converts far higher than a public share (higher intent, social pressure to respond).
  • Mutual incentive: both sides get free astrologer minutes, so the invitee is rewarded for joining, not just the inviter — this is what keeps K-factor above 1 instead of decaying after one hop.
  • Loop-back CTA: after seeing their result, the invitee is prompted to start their own match — turning every new user into a new inviter within the same session.
